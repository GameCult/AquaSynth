# Physical Voice Modeling Research Packet

This folder preserves the source material and distilled direction for the next
AquaSynth voice architecture pass.

- `SUMMARY.md`: distilled implementation summary.
- `PEOPLE.md`: practical researcher/implementation map.
- `SOURCES.md`: source manifest, URLs, notes, and hashes.
- `sources/`: downloaded/captured source files where available.
- `talks/TALKS.md`: captured talks, transcripts where available, and transcript
  availability notes.

The working conclusion: model voices as acoustic port networks with continuous
morphology, source ports, branch/radiation ports, and wave-clock policies. Pink
Trombone is a larynx-shaped reference configuration, not the architecture.
